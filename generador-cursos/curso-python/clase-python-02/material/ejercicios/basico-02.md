# 🟢 Básico 02 — Función con parámetro y retorno

## 🧩 Problema

Escribe una función `doble(numero)` que **devuelva** (no que imprima) el doble del número
que recibe. En el programa principal, imprime el doble de `4` y el doble de `25` usando
la función.

## 📥 Entrada

- Un número entero, pasado como argumento en cada llamada (`4` y `25`).

## ⚙️ Proceso esperado

1. Definir `doble(numero)` con un parámetro.
2. En el cuerpo, usar `return` para devolver `numero * 2`.
3. En el programa principal, imprimir el resultado de `doble(4)` y de `doble(25)`.

## 📤 Salida

```text
8
50
```

## 🚧 Restricciones

- La función debe usar `return`, no `print`.
- El programa principal es quien imprime, llamando a la función.
- Identificadores y comentarios en español.

## 📊 Dificultad

Básico

## 🎓 Resultados de aprendizaje

- RA-2: definir una función con `def` e invocarla.
- RA-3: usar un parámetro para que la función reciba datos.
- RA-4: devolver un valor con `return` y usarlo en el programa.
